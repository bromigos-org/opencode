# About this fork (bromigos-org/opencode)

This is an unmodified GitHub fork of
[anomalyco/opencode](https://github.com/anomalyco/opencode). Every other
document in this repository is upstream's.

- **Changes:** none. The default branch `dev` has no commits of its own; it was
  last synced with upstream on 2026-07-31 and is now several hundred commits
  behind it.
- **Use:** nothing builds or runs this fork. The only "opencode" in the Bromigos
  repos is the hosted OpenCode Go model subscription, which is routed through
  LiteLLM and has nothing to do with this code (checked 2026-10-05).
- **Status:** candidate for archiving.
